1 — Alphabets, Mots et Langages

Définitions fondamentales et opérations de base

Alphabet Σ

Ensemble fini non vide de symboles (lettres). Ex : Σ = {a, b, c}

Mot

Suite finie de lettres. Longueur |m|. Mot vide ε (longueur 0).

Langage

Tout ensemble de mots sur Σ. Peut être fini ou infini.

Concaténation

Opérations sur les mots

// Concaténation de m et p
mp = juxtaposition de m puis p

// Puissance
m^k = m · m · ... · m (k fois), m^0 = ε

// Neutralité du mot vide
∀p : pε = p = εp
Opérations sur les langages

Opérations ensemblistes

L₁ ∪ L₂ · · · union
L₁ ∩ L₂ · · · intersection
L₁ − L₂ · · · différence

Concaténation L₁ • L₂

Tous les mots obtenus en concaténant un mot de L₁ avec un mot de L₂.
{ε} est neutre pour •

Étoile de Kleene L* et L⁺

L+ = L ∪ L^2 ∪ L^3 ∪ ... (nb non nul de concat.)
L* = {ε} ∪ L+ = L^0 ∪ L ∪ L^2 ∪ ... (nb quelconque)

Σ* = tous les mots sur Σ
L+ = L* ssi ε ∈ L

2 — Expressions Régulières

Premier outil pour décrire les langages réguliers de façon compacte

Une expression régulière (ER) est définie par induction sur un alphabet Σ disjoint de ∆ = {∅, λ, (, ), *, |}

Définition inductive

Expressions primitives

  • ∅ → langage vide
  • λ → {ε} (mot vide)
  • x ∈ Σ → {x} (lettre seule)

Expressions composées

  • αβ → concaténation Lα • Lβ
  • (α|β) → union Lα ∪ Lβ
  • (α)* ou α* → étoile Lα*

Notations abrégées

Abréviations courantes

(α)+ = α(α)* = (α)*α (au moins une fois)
(α)^k = α·α·...·α (k fois)
α β γ ≡ (α|β)γ ≡ α(β|γ) (raccourci pour union)
Langages réguliers
Définition

Un langage sur Σ est dit régulier (rationnel) s'il est le langage associé à une expression régulière sur Σ.

Exemple d'examen — Juin 2017

Sur Σ = {a,b,c,d} :

L₁ = aa*(c|d)*(cd)* → commence par au moins 1 a
L₂ = (aa)*(c|d)*(cd)* → nombre pair de a
L₃ = {(aa)^n (c|d)^p (cd)^n | n,p ∈ ℕ} → autant de aa que de cd

Preuve L₁≠L₂≠L₃ : le mot a ∈ L₁ mais ∉ L₂ ni L₃ ; le mot aa ∈ L₂ mais ∉ L₃ (car n=1 → aacd ≠ aa).

3 — Grammaires Régulières

Deuxième outil : règles formelles pour construire les mots d'un langage

Définition — Quadruplet G = (Σ, N, <S>, P)

Σ = symboles terminaux · N = symboles non terminaux · <S> = axiome · P = règles de dérivation

Formes des règles de dérivation

Forme 1

<A> → m
m ∈ Σ*

Forme 2

<A> → m<B>
m ∈ Σ*, <B> ∈ N

Forme 3

<A> → <B>
<A>,<B> ∈ N
Grammaire normalisée

Une grammaire est normalisée si chaque membre droit est soit ε, soit x (lettre seule), soit x<Z> (lettre + non-terminal). Toute grammaire régulière peut être normalisée sans changer le langage.

// Règle non normale → remplacement
<X> → ab<Z> devient :
<X> → a<Y>
<Y> → b<Z> (ajout du non-terminal <Y>)
Construction grammaire ↔ expression régulière
Règles de construction
∅

<S> → x<S> (boucle infinie) — génère le langage vide

λ

<S> → ε — génère uniquement {ε}

x∈Σ

<S> → x — génère {x}

(α|β)

Ajouter axiome <S> avec règle <S> → <Sα> | <Sβ> + garder toutes règles de Gα et Gβ

αβ

Garder <Sα> comme axiome. Remplacer toute règle terminale <X>→u de Gα par <X>→u<Sβ>

(α)*

Ajouter <S> avec règle <S>→ε|<Sα>. Toute règle terminale <X>→u devient <X>→u<S>

Raisonnement par états (exemple)

Mots avec nombre pair de 'a' sur {a,b,c}

<S> → ε (0 a : accepté)
<S> → a<A> (ajoute un a → nb impair)
<S> → b<S> c<S> (b ou c : reste pair)

<A> → a<S> (ajoute un a → nb pair)
<A> → b<A> c<A> (b ou c : reste impair)

Expression régulière : (b | c | a(b|c)*a)*

4 — Automates de Moore

Troisième outil : reconnaisseur déterministe de langages réguliers

Définition — Quintuplet M = (Σ, E, e₀, A, t)

Σ = alphabet · E = états (fini non vide) · e₀ = état initial unique · A ⊆ E = états acceptants · t : Σ × E → E = fonction de transition

Propriétés d'un automate de Moore

Conditions nécessaires

  • ✓ Un et un seul état initial
  • ✓ Pour chaque état et chaque lettre : exactement une flèche

Langage reconnu

Tous les mots qui, à partir de e₀, conduisent par transitions à un état final acceptant.

Table de transitions

Table à double entrée : états en colonnes, lettres en lignes. Chaque case donne l'état d'arrivée. États acceptants mis en évidence (ex: rouge). Flèche ↓ au-dessus de l'état initial.

Σ \ E ↓ 1 (init) 2 3 ✓ 4 ✓ 5
a32435
b25224

Exemple : de l'état 1, si lettre 'a' → état 3 (acceptant). Mot ababbaa → termine sur état 4 ✓ : accepté.

Grammaire associée à un automate de Moore
Conversion automate → grammaire régulière normalisée
1

Associer à chaque état i le symbole non terminal <i>

2

L'axiome correspond à l'état initial

3

Pour chaque flèche x de i vers j : ajouter <i> → x<j>

4

Pour chaque état acceptant i : ajouter <i> → ε

5 — NDFA (Non Deterministic Finite Automaton)

Automate fini non déterministe — plus souple, souvent plus simple à concevoir

Définition — Quintuplet M = (Σ, E, I, A, t)

Σ = alphabet · E = états · I ⊆ E = ensemble d'états initiaux (plusieurs !) · A ⊆ E = états acceptants · t : Σ × E → P(E)

Différences clés avec l'automate de Moore

Plusieurs états initiaux

I peut contenir plusieurs états (marqués →)

Non déterminisme

Depuis un état et une lettre, on peut atteindre 0, 1 ou plusieurs états.

Blocage possible

Aucune transition prévue pour certaines configurations : le mot n'est pas reconnu par ce chemin.

Un mot est reconnu par un NDFA s'il existe au moins un chemin de transitions (parmi tous les chemins possibles) qui mène d'un état initial à un état acceptant.

Table de transitions NDFA

Chaque case contient un ensemble d'états (possiblement vide : −). Plusieurs flèches ↓ sont possibles. Un automate de Moore est un cas particulier de NDFA où I = {e₀} et chaque case contient exactement un état.

6 — Subset Construction & Opérations

Convertir un NDFA en automate de Moore équivalent

Principe

Chaque état du nouvel automate de Moore est un sous-ensemble des états du NDFA. L'état initial est l'ensemble I des états initiaux du NDFA.

Algorithme — Subset Construction
1

L'état initial de l'automate de Moore = I (ensemble des états initiaux du NDFA). Il est acceptant si I contient un état acceptant.

2

Pour chaque état D non traité et chaque lettre x : τ(x, D) = ⋃_{e∈D} T(x, e) = tous les états NDFA atteignables depuis D par x.

3

Un état est acceptant s'il contient au moins un état acceptant du NDFA.

4

Si aucun état n'est atteignable → créer l'état poubelle − (non acceptant, avec boucle sur lui-même pour toute lettre).

5

Répéter jusqu'à ce que tous les états soient traités. Nombre max d'états : 2^|E|.

La subset construction ne produit pas nécessairement un automate minimal. Elle donne un automate de Moore correct mais pas forcément optimisé.

Opérations sur les automates

Union L₁ ∪ L₂

Rassembler M₁ et M₂ en un NDFA (deux états initiaux), puis appliquer la subset construction.

Concaténation L₁ • L₂

  1. Mettre M₁ et M₂ ensemble
  2. Pour toute flèche x de i→j où j est acceptant dans M₁ : ajouter flèche x de i → état initial de M₂
  3. Si état initial M₁ non acceptant : retirer état initial M₂ des états initiaux
  4. Si état initial M₂ non acceptant : rendre non acceptants tous les états acceptants de M₁
  5. Subset construction

Étoile L*

  1. Ajouter un état acceptant eᵢ comme nouvel état initial
  2. Pour chaque flèche x de l'ancien état initial vers j : copier x de eᵢ vers j
  3. Pour chaque flèche x de i vers un état acceptant j de M : ajouter flèche x de i vers eᵢ
  4. Retirer l'ancien état initial des états initiaux
  5. Subset construction
Conversion grammaire → automate de Moore
Grammaire régulière normalisée → NDFA → automate de Moore
1

Pour chaque non-terminal <I> : ajouter un état I au NDFA

2

Axiome = état initial

3

Règle <I>→x<J> : flèche x de I vers J

4

Règle <I>→ε : état I devient acceptant

5

Règle <I>→x (x∈Σ) : flèche x de I vers l'état universel Ω (acceptant)

6

Appliquer la subset construction au NDFA obtenu

7 — Automate de Moore Minimal (Moore-Nerode)

Fusionner les états équivalents pour obtenir l'automate optimal unique

Tout langage régulier L est reconnu par un et un seul automate de Moore minimal M_L. Si deux automates ont le même nombre d'états et reconnaissent le même langage, ils ne sont pas optimisés.

Algorithme de Moore-Nerode
Étapes de l'algorithme
∼₀

Étape 0 : Partition initiale en 2 classes : {états acceptants} et {états non acceptants}.
E/∼₀ = { {acceptants}, {non acceptants} }

∼ₙ

Étape n : e ∼ₙ f ssi e ∼ₙ₋₁ f ET pour toute lettre x, les états d'arrivée e₂=t(x,e) et f₂=t(x,f) vérifient e₂ ∼ₙ₋₁ f₂.
→ Si un état de la même classe donne des destinations dans des classes différentes : on scinde la classe.

Stop

Critère d'arrêt : On s'arrête quand ∼ₙ = ∼ₙ₋₁ (aucune nouvelle partition).

Fusion

Fusion : États dans la même classe finale → fusionnés en un seul état. Le résultat est acceptant si les états fusionnés l'étaient. Les flèches se redirigent vers l'état fusionné.

Exemple complet — 8 états (0..7)

Données initiales

Σ\E↓0*1*23*45*67
a27365711
b46452566

* = états acceptants (0,1,3,5)

Déroulement des partitions

∼₀ : [0,1,3,5] | [2,4,6,7]
∼₁ : [0,1] | [3,5] | [2,4,6,7] ← {0,1} et {3,5} se séparent car destinations différentes
∼₂ : [0,1] | [3,5] | [2,4] | [6,7] ← [2,4,6,7] se scinde
∼₃ : [0] | [1] | [3,5] | [2,4] | [6,7] ← [0,1] se scinde
∼₄ = ∼₃ → ARRÊT !

Résultat — États fusionnés

{0} → état 0 (init, accept.) {1} → état 1 (accept.) {3,5} → état 3 (accept.) {2,4} → état 2 (accept.) {6,7} → état 6 (accept.)

8 états → 5 états dans l'automate optimisé.
