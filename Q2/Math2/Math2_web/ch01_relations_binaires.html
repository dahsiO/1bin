Définitions de base
Couple

Un couple (a, b) est une paire ordonnée. Ordonné signifie que l'ordre compte :

(a ≠ b) ⟹ (a, b) ≠ (b, a) (a, b) = (c, d) ⟺ a = c ∧ b = d

Un couple identique est de la forme (a, a).

Produit cartésien

A × B = { (a, b) | a ∈ A ∧ b ∈ B } — tous les couples possibles.

|A × B| = |A| · |B|

Notation raccourcie : A × A = A²

Exemple : A = {1,2}, B = {a,b,c} → A×B = {(1,a),(1,b),(1,c),(2,a),(2,b),(2,c)}, |A×B| = 6

Relation binaire

R est une relation de A vers B si et seulement si R ⊆ A × B.

A = ensemble de départ · B = ensemble d'arrivée.

Notation infixe : a R b au lieu de (a, b) ∈ R.

Cas particulier : si R est une relation de A vers A, on dit que R est une relation sur A.

Relation identité 1ₐ

1ₐ = { (a, a) | a ∈ A } — chaque élément mis en relation avec lui-même.

(x, y) ∈ 1ₐ ⟺ x = y
Domaine & Image

Dom(R) = { a ∈ A | ∃ b ∈ B : (a,b) ∈ R } — éléments de départ qui ont au moins une image.

Im(R) = { b ∈ B | ∃ a ∈ A : (a,b) ∈ R } — éléments d'arrivée qui ont au moins un antécédent.

5 propriétés des relations sur un ensemble
Ces 5 propriétés ne s'appliquent qu'aux relations sur un seul ensemble E (R ⊆ E²).

♻ Réflexivité

∀x ∈ E : x R x ⟺ 1ₑ ⊆ R

Digraphe : TOUS les éléments ont une boucle.

Prouver : montrer x R x vrai ∀x. Réfuter : trouver x tel que x R x est faux.

Ex. "est multiple de" sur ℕ : n est multiple de n ✓

⊘ Antiréflexivité

∀x ∈ E : ¬(x R x) ⟺ 1ₑ ∩ R = ∅

Digraphe : AUCUN élément n'a de boucle.

Prouver : x R x faux ∀x. Réfuter : trouver x tel que x R x est vrai.

Ex. "strictement inférieur" sur ℕ : n < n est toujours faux ✓

↔ Symétrie

∀x,y ∈ E : x R y ⟹ y R x ⟺ R = R⁻¹

Digraphe : que des boucles et des doubles flèches — aucune flèche simple.

Prouver : supposer xRy, montrer yRx. Réfuter : trouver x,y tels que xRy mais ¬(yRx).

Ex. "est frère ou sœur de" ✓

→ Antisymétrie

∀x,y ∈ E : (x R y) ∧ (x≠y) ⟹ ¬(y R x) ⟺ R ∩ R⁻¹ ⊆ 1ₑ

Digraphe : aucune double flèche — que des boucles et flèches simples.

Prouver : supposer xRy et x≠y, montrer ¬(yRx). Réfuter : trouver x≠y tels que xRy ET yRx.

Ex. "divise" sur ℕ₀ ✓

⤳ Transitivité

∀x,y,z ∈ E : (x R y) ∧ (y R z) ⟹ (x R z) ⟺ R ∘ R ⊆ R

Digraphe : si chemin e1→e3→e2 alors flèche e1→e2 doit exister.

Prouver : supposer xRy et yRz, montrer xRz. Réfuter : trouver x,y,z tels que xRy, yRz mais ¬(xRz).

Ex. "est ancêtre de" ✓

⚠ Pièges classiques : non-réflexive ≠ antiréflexive · non-symétrique ≠ antisymétrique. Une relation peut n'être ni l'une ni l'autre, ou être les deux à la fois. Toujours vérifier les 5 propriétés indépendamment.
✓ Récapitulatif opérationnel : Antiréflexive ⟺ 1ₑ ∩ R = ∅ · Symétrique ⟺ R = R⁻¹ · Antisymétrique ⟺ R ∩ R⁻¹ ⊆ 1ₑ · Transitive ⟺ R ∘ R ⊆ R
✅

Clôtures
Définition

Clôturer R pour une propriété p = ajouter le minimum de couples pour que R acquière p.

La clôture est unique. On ne peut qu'ajouter des flèches, jamais en retirer.

✓ Clôture réflexive possible ✓ Clôture symétrique possible ✓ Clôture transitive possible ✗ Clôture antiréflexive impossible ✗ Clôture antisymétrique impossible

Antiréflexive et antisymétrique nécessitent de retirer des flèches (boucles / doubles flèches) → impossible comme clôture.

Clôture réflexive

R ∪ 1ₑ

Ajouter une boucle (x,x) sur chaque élément x qui n'en a pas encore.

Clôture symétrique

R ∪ R⁻¹

Pour chaque flèche simple a → b, ajouter b → a.

Clôture transitive

R⁺ (calculée par Warshall)

Pour tout chemin a → ⋯ → b, ajouter la flèche directe a → b.

⚠ L'ordre des clôtures successives est important !
Clôture symétrique puis transitive ≠ Clôture transitive puis symétrique.
La clôture sym. suivie de la clôture trans. donne une relation transitive. L'inverse pas nécessairement.
⚙️
Opérations sur les relations

↩ Réciproque R⁻¹

x R⁻¹ y ⟺ y R x
Inverser le sens de toutes les flèches. R⁻¹ ⊆ B × A.

Symétrique ⟺ R = R⁻¹

⊘ Complémentaire R̄

x R̄ y ⟺ ¬(x R y)
Flèche dans R̄ ssi pas de flèche dans R. R̄ ⊆ A × B.

∪ Union R ∪ S

x (R∪S) y ⟺ x R y ∨ x S y
Même ensemble de départ et d'arrivée requis.

∩ Intersection R ∩ S

x (R∩S) y ⟺ x R y ∧ x S y
Flèche présente dans les deux relations.

Composée S ∘ R

R de A vers B · S de B vers C. L'ensemble d'arrivée de R = ensemble de départ de S.

x (S ∘ R) y ⟺ ∃z ∈ B : (x R z) ∧ (z S y)

Se lit "R puis S". S ∘ R ⊆ A × C.

Exemple concret : M = "est mère de", P = "est père de" sur les humains :

  • M ∪ P = "est parent de"
  • M ∘ P = "est grand-père maternel de" (∃z : x est père de z et z est mère de y)
⚠ Pas commutative : S ∘ R ≠ R ∘ S en général.
Neutre : 1ᴮ ∘ R = R = R ∘ 1ᴬ (les identités sont neutres pour ∘).
Attention : R⁻¹ ∘ R ≠ 1ᴬ et R ∘ R⁻¹ ≠ 1ᴮ en général.
Propriétés reformulées avec les opérations :
Antiréflexive ⟺ 1ₑ ∩ R = ∅  ·  Symétrique ⟺ R = R⁻¹  ·  Antisymétrique ⟺ R ∩ R⁻¹ ⊆ 1ₑ  ·  Transitive ⟺ R ∘ R ⊆ R

Chemins dans un digraphe & puissances de relation
Vocabulaire digraphe

Sommet = nœud (élément de E) · Arête = flèche (paire (x,y) ∈ R).

Chemin de x à y : séquence d'arêtes consécutives, de x à y.

Cycle : chemin de x à x (l'origine = l'extrémité).

Longueur : nombre d'arêtes du chemin.

Chemin hamiltonien : chemin sans cycle intérieur. Longueur max dans un digraphe à n sommets = n.

Puissance d'une relation R^k
R⁰ = 1ₑ R^k = R^(k-1) ∘ R = R composée k fois

Interprétation : x R^k y ⟺ il existe un R-chemin de longueur k de x à y.

Propriétés algébriques :

R^n ∘ R^p = R^(n+p) (R^k)^n = R^(k·n)
Fermeture transitive R⁺

x R⁺ y ⟺ il existe un R-chemin (de n'importe quelle longueur > 0) de x à y.

R⁺ = R¹ ∪ R² ∪ … ∪ Rⁿ (si |E| = n)

Calculer R⁺ = faire la clôture transitive de R.

⚠ R⁺ n'inclut pas R⁰ = 1ₑ (pas nécessairement de boucle sur chaque sommet).

Algorithme naïf pour R⁺ : O(n⁴)
Calculer R¹, R², …, Rⁿ et les unir. Chaque composée est O(n³), répétée n fois → O(n⁴). Inefficace ! On utilise Warshall : O(n³).
// Algorithme naïf O(n⁴) — pour comprendre, pas pour utiliser
R⁺ = ∅                              → R⁺ vide au départ
Rk = 1ₑ                             → initialisation à R⁰
pour k = 1 à n :
  Rk = Rk ∘ R                     → calcul de R^k
  R⁺ = R⁺ ∪ Rk                   → ajout de R^k
fin-pour

Algorithme de Warshall — O(n³)
Relations de Warshall Rk

Soit R sur E = {1, 2, …, n}. On définit :

x Rk y ⟺ ∃ R-chemin de x à y dont tous les sommets intérieurs ∈ {1, …, k}

R₀ = R (chemins directs = longueur 1, sommets intérieurs dans ∅)
Rn = R⁺ (n'importe quel chemin, sommets intérieurs dans E entier)
Rk₋₁ ⊆ Rk (on ajoute au fur et à mesure)

Propriété récurrente — clé de l'algorithme
a Rk b ⟺ (a Rk₋₁ b) ∨ ((a Rk₋₁ k) ∧ (k Rk₋₁ b))

Il existe un chemin a → b via sommets ≤ k, soit parce qu'il existait déjà sans passer par k, soit parce que a peut atteindre k (a→k existe) ET k peut atteindre b (k→b existe).

Algorithme complet

R⁺ = R                           → initialisation à R₀

pour k = 1 à n faire               → on traite chaque sommet k
  pour i = 1 à n faire
    si (i, k) ∈ R⁺ alors         → flèche arrivant à k
      pour j = 1 à n faire
        si (k, j) ∈ R⁺ alors     → flèche partant de k
          ajouter (i, j) à R⁺   → chemin i → k → j
        fin-si
      fin-pour
    fin-si
  fin-pour
fin-pour

→ Complexité : O(n²) par étape × n étapes = O(n³)

Méthode manuelle — étape k

  • Partir de Rk₋₁ (ou de R pour k=1)
  • Repérer toutes les flèches arrivant à k (les "i" tels que (i,k) ∈ R⁺)
  • Repérer toutes les flèches partant de k (les "j" tels que (k,j) ∈ R⁺)
  • Pour chaque paire (i, j) : ajouter la flèche i → j si elle n'existe pas encore
  • Si aucune flèche ne part de k OU n'arrive à k → Rk = Rk₋₁ (rien à ajouter)
Exemple — E = {2,3,6,7,8,12}, ordre choisi : 7,3,6,2,12,8
Étape 7 : 3→7→2 → ajouter (3,2) · Étape 3 : 2→3→{7,6,2,12} → ajouter 4 flèches · Étape 6 : aucune flèche ne part de 6 → R₃=R₂ · Étape 2 : 7→2→{7,3,6,12} → ajouter 4 flèches · Étape 12 : 8→12→6 → ajouter (8,6) · Étape 8 : aucune flèche n'arrive à 8 → R₆=R₅.
⚠ L'ordre des sommets choisi pour k peut varier librement. Le résultat final R⁺ est toujours le même, quel que soit l'ordre choisi.
