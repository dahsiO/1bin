Probabilités — Rappels
Vocabulaire essentiel

Expérience aléatoire : expérience dont les résultats dépendent du hasard (ex : jet d'un dé).

Éventualité : un résultat possible. Univers Ω : ensemble de toutes les éventualités.

Événement : sous-ensemble de l'univers. Probabilité : mesure de vraisemblance ∈ [0, 1].

Distribution de probabilités (fonction de masse)

Fonction f(x) qui associe à chaque éventualité x sa probabilité. Elle vérifie :

1) 0 ≤ f(eᵢ) ≤ 1 pour tout i 2) f(e₁) + f(e₂) + ··· + f(eₙ) = 1 (somme = 1)

Exemple — Dé équilibré à 6 faces

Chaque face a la même probabilité :

f(1) = f(2) = f(3) = f(4) = f(5) = f(6) = 1/6

Équiprobabilité : p(E) = cas favorables / cas possibles

Exemple — Dé pipé

p(6) = 1/2, les autres faces équiprobables :

5·p(1) = 1/2 ⟹ p(1) = 1/10 f(1)=f(2)=f(3)=f(4)=f(5) = 1/10 f(6) = 1/2
Matrice colonne-stochastique

Une matrice est colonne-stochastique si :

→ tous ses éléments sont ≥ 0

→ la somme de chaque colonne = 1

Autrement dit : chaque colonne est une distribution de probabilités.

Processus de Markov — Définition
Définition

Un processus de Markov homogène à temps discret et à états finis est la modélisation d'un système évoluant entre plusieurs états au cours du temps, permettant la prévision de l'état futur.

Il est défini par :

1
Des états e₁, e₂, …, eₙ (états possibles du système)
2
Des distributions de probabilités f₁, …, fₙ où fᵢ(eⱼ) = probabilité d'être en eⱼ à t+1 si on était en eᵢ à t

4 propriétés obligatoires :

Propriété de Markov

La seule info nécessaire pour prédire l'état à t+1 est l'état à t (pas l'historique).

Homogénéité

Les distributions f₁, …, fₙ ne changent pas au cours du temps.

États finis

Le nombre d'états est fini.

Temps discret

L'intervalle entre 2 états successifs est toujours le même.

💡 Application informatique : tout diagramme d'états (gestion de projets, de stages, machines à états) est modélisable par un processus de Markov.

Exemple introductif — Individu endetté :

Énoncé

Un individu non endetté a 1 chance sur 3 de devenir endetté le jour suivant. Un individu endetté a 1 chance sur 6 de régler ses dettes.

États et transitions

État 1 = Non endetté État 2 = Endetté P(rester en 1) = 2/3 P(1→2) = 1/3 P(rester en 2) = 5/6 P(2→1) = 1/6

Matrice de transition
Définition

La matrice de transition P contient les distributions de probabilités mises en colonnes :

P[i][j] = pᵢⱼ = probabilité d'être en état eᵢ à t+1 si on était en état eⱼ à t ⟹ Chaque colonne j = distribution de probabilités depuis l'état j ⟹ P est une matrice CARRÉE COLONNE-STOCHASTIQUE
⚠️ Attention à la convention : P[i][j] = de j vers i (ligne = arrivée, colonne = départ).

Exemple — Individu endetté :

💡 Vérification : la somme de chaque colonne doit toujours valoir 1 : 2/3 + 1/3 = 1 ✔, 1/6 + 5/6 = 1 ✔

Règle de lecture graphe → matrice :

1
Chaque état = une colonne de la matrice.
2
La probabilité d'une flèche eᵢ → eⱼ va dans P[j][i] (ligne j, colonne i).
3
La somme des probabilités des flèches sortant d'un même état = 1 ⟹ somme de la colonne = 1.

Prévision de l'état
Formule de prévision

Si d⁽ᵗ⁾ est le vecteur de distribution à l'instant t, alors :

d⁽ᵗ⁺¹⁾ = P · d⁽ᵗ⁾ d⁽ᵗ⁾ = Pᵗ · d⁽⁰⁾ (depuis l'état initial)

Le vecteur d⁽ᵗ⁾ est une colonne dont chaque entrée dᵢ = probabilité d'être en état i à l'instant t. La somme = 1.

Exemple — Individu endetté :

À l'instant t : autant de chances d'être endetté que non endetté → d⁽ᵗ⁾ = (1/2, 1/2)

Calcul de d⁽ᵗ⁺¹⁾ = P · d⁽ᵗ⁾
d⁽ᵗ⁺¹⁾ = ( 2/3 1/6 ) · ( 1/2 ) = ( 2/3×1/2 + 1/6×1/2 ) = ( 5/12 )
          ( 1/3 5/6 )   ( 1/2 )    ( 1/3×1/2 + 5/6×1/2 )    ( 7/12 )
✔ À t+1 : probabilité 7/12 d'être endetté, 5/12 de ne pas l'être.

États, Périodicité & Classes
État transient

État dont le système n'est pas certain de pouvoir revenir après l'avoir quitté.

Transient → dans une distribution stable, sa composante = 0.

État récurrent

État dans lequel le système a toujours la possibilité de revenir après l'avoir quitté.

Récurrent → contribue à la distribution stable.

Classe de communication & Période

Communication : eᵢ communique avec eⱼ s'il existe un chemin de eᵢ vers eⱼ ET un chemin de eⱼ vers eᵢ. Un état communique toujours avec lui-même.

Classe de communication : ensemble maximal d'états qui communiquent tous entre eux.

Période d'un état : PGCD des longueurs de chemin possibles pour y revenir.

Processus irréductible (ergodique) : une seule classe de communication.

Classe apériodique : période = 1.

Exemple — Labyrinthe (7 états) :

ClasseÉtatsTypePériodeRemarque

C₂{2, 3, 4, 5, 6}TransientPériode 2Boucle de longueur 2, 4, 6… → PGCD = 2

Distribution stable
Définition

Une distribution d est stable si elle n'évolue plus avec le temps :

P · d = d

Interprétation : d donne la proportion de temps passé dans chaque état sur le long terme.

Théorème d'existence

Tout processus de Markov possède toujours au moins une distribution stable.

Théorème d'unicité

Si le processus n'a qu'une seule classe récurrente → distribution stable unique.

Théorème de convergence

Si le processus a une seule classe récurrente et que celle-ci est apériodique (période = 1) → la suite d⁽ᵏ⁺¹⁾ = P·d⁽ᵏ⁾ converge vers l'unique distribution stable.

Méthode pour trouver d stable :

1
Poser d = (x₁, x₂, …, xₙ) et écrire P·d = d
2
Ajouter la contrainte x₁ + x₂ + … + xₙ = 1
3
Résoudre le système par la méthode de Gauss
4
Les états transients ont automatiquement leur composante = 0

Exemple complet — Individu endetté :

Vérification des conditions de convergence ▼
a
Classes : 1 seule classe C₁ = {1, 2} → irréductible
b
Type : tous récurrents, période = 1 → apériodique
c
✔ Processus irréductible et apériodique → convergence vers l'unique distribution stable.
Résolution du système P·d = d ▼

Soit d = (x, y). On a les conditions :

x + y = 1 (2/3)x + (1/6)y = x → -(1/3)x + (1/6)y = 0 (1/3)x + (5/6)y = y → (1/3)x - (1/6)y = 0

Échelonnage Gauss :

1 1 | 1 → 1 1 | 1 -1/3 1/6| 0 →×(-6) 2 -1 | 0 1/3 -1/6| 0 →×6 2 -1 | 0 Après élimination : 1 1 | 1 0 -3 | -2 0 0 | 0 Résolution : y = 2/3 , x = 1/3
✔ Distribution stable : d = (1/3, 2/3)

L'individu sera endetté 2/3 du temps (≈ 66,7%) sur le long terme.

Temps de parcours moyen
Définition

Le temps de parcours moyen pour aller de l'état eᵢ à l'état eⱼ est le nombre d'unités de temps moyen nécessaires.

Méthode :

1
Soit tᵢ le temps moyen pour aller de l'état eᵢ à l'état cible eⱼ. Poser tⱼ = 0.
2
Pour tout i ≠ j : tᵢ = 1 + Σₖ pₖᵢ · tₖ (1 unité de temps + temps pondéré depuis les états atteignables)
3
Réécrire le système sous forme matricielle et résoudre par Gauss.
⚠️ Pour que le calcul ait un sens, il faut que l'état d'arrivée appartienne à la seule classe récurrente du processus.

Exemple — Chien (état 1 → état 7) :

Écriture des équations de temps ▼
t₇ = 0 (état d'arrivée) t₁ = 1 + t₂ (1→2 obligatoire) t₂ = 1 + t₃ t₃ = 1 + t₄ t₄ = 1 + (1/2)·t₅ + (1/2)·t₆ (bifurcation 50/50) t₅ = 1 + t₂ (5→2 obligatoire) t₆ = 1 + (1/2)·t₄ + (1/2)·t₇ = 1 + (1/2)·t₄

Réécriture en système linéaire :

t₁ - t₂ = 1 t₂ - t₃ = 1 t₃ - t₄ = 1 t₄ - (1/2)t₅ - (1/2)t₆ = 1 -t₂ + t₅ = 1 -(1/2)t₄ + t₆ = 1
Résolution (Gauss) et résultat ▼

Après échelonnage de la matrice 6×7 :

Système échelonné : t₆ = 7 t₅ - 2t₆ = 1 → t₅ = 15 -t₄ + 2t₆ = 2 → t₄ = 12 t₃ - t₄ = 1 → t₃ = 13 t₂ - t₃ = 1 → t₂ = 14 t₁ - t₂ = 1 → t₁ = 15
✔ En moyenne : 15 déplacements pour aller du sas 1 au sas 7.

Exemple — Échelle (sol → marche 4) :

Système et résolution ▼
t₄ = 0 t₀ = 1 + t₁ t₁ = 1 + (1/2)·t₀ + (1/2)·t₂ t₂ = 1 + (1/2)·t₁ + (1/2)·t₃ t₃ = 1 + (1/2)·t₂ + (1/2)·t₄ Système linéaire : t₀ - t₁ = 1 -t₀ + 2t₁ - t₂ = 2 -t₁ + 2t₂ - t₃ = 2 -t₂ + 2t₃ = 2 Après Gauss (échelonnage simple) : t₃ = 7, t₂ = 12, t₁ = 15, t₀ = 16
✔ Temps moyen pour atteindre la marche 4 : 16 changements d'échelon.

Méthode complète pour un exercice d'examen :

1
Identifier les états et les numéroter.
2
Tracer le graphe : flèches avec probabilités, vérifier que la somme des flèches sortant de chaque état = 1.
3
Écrire la matrice P : colonne j = distribution depuis l'état j.
4
Classifier : trouver les classes de communication, le type (transient/récurrent), la période.
5
Distribution stable : résoudre P·d = d avec Σdᵢ = 1 par Gauss.
6
Temps de parcours : écrire tᵢ = 1 + Σpₖᵢ·tₖ pour chaque état (sauf l'état cible), résoudre par Gauss.
⚠️ Pièges classiques :
• La colonne j de P représente les transitions depuis l'état j (pas depuis l'état i).
• Somme des colonnes = 1, pas des lignes.
• Pour le temps de parcours : multiplier par la probabilité de chaque transition.
• Pour la distribution stable : ne pas oublier la contrainte Σdᵢ = 1 dans le système.
