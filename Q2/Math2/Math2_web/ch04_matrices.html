🧮Définitions fondamentales

Qu'est-ce qu'une matrice ?

Une matrice est un tableau rectangulaire de nombres organisés en lignes et colonnes. C'est un outil puissant pour modéliser des données structurées : états de jeu, commandes, populations…

Une matrice m × n est un tableau de m lignes et n colonnes.
Si tous les éléments sont réels : A ∈ ℝm×n
L'élément en ligne i, colonne j se note aij
[
a11a12…a1n a21a22…a2n ⋮⋮⋱⋮ am1am2…amn
Matrice A ∈ ℝm×n
]

Une grille 3×3 avec cases vivantes (1) ou mortes (0) se représente directement comme une matrice booléenne :

Matrice carrée (n×n)

Même nombre de lignes et de colonnes. Ordre n.

1 sur la diagonale, 0 ailleurs. Équivalent matriciel de "1".

Propriété clé : A · In = In · A = A  (pour toute matrice carrée A d'ordre n)

Notation de l'élément aij

Pour A ∈ ℝ3×4, l'élément ligne 1, colonne 3 est a13

aij ← ligne i, colonne j

➕Addition de matrices

Règle
L'addition de deux matrices se fait élément par élément (mêmes indices).
Condition : les deux matrices doivent avoir les mêmes dimensions.
Si C = A + B  alors  cij = aij + bij

Multiplication par un scalaire

Multiplier une matrice par un réel k revient à multiplier tous les éléments par k.

k · A = matrice où chaque élément aij devient k · aij
2 ·
2 1 3 4
=
4 2 6 8
⚠ Condition OBLIGATOIRE pour l'addition : A et B doivent avoir exactement les mêmes dimensions m×n. Sinon, l'addition est IMPOSSIBLE

✖️Multiplication de matrices

Règle fondamentale
Si C = A · B avec A ∈ ℝm×p et B ∈ ℝp×n, alors C ∈ ℝm×n

cij = ligne i de A × colonne j de B (produit scalaire)
cij = ai1·b1j + ai2·b2j + … + aip·bpj
Condition : le nombre de colonnes de A doit égaler le nombre de lignes de B
A (m×p) · B (p×n) = C (m×n)

⚠ Pièges classiques — NON-commutativité
La multiplication matricielle N'EST PAS commutative !
En général : A·B ≠ B·A

Contre-exemple : soit A = [[1,2],[3,6]] et B = [[2,4],[-1,-2]]

A · B =
00 00
= O₂
Matrice nulle !
B · A =
1428 -7-14
≠ O₂
Piège : A·B = 0 n'implique pas que A = 0 ou B = 0 !
C'est une différence fondamentale avec les nombres réels.

🔄Transposée

Définition
La transposée d'une matrice A, notée AT, est obtenue en intervertissant lignes et colonnes.

Si B = AT alors bij = aji

Si A est m×n, alors AT est n×m
Visualisation interactive
5241 3023 2150
A (3×4) — ligne 1, ligne 2, ligne 3
⟹
532 201 425 130
AT (4×3) — colonnes = ex-lignes

Les lignes de A deviennent les colonnes de AT (et vice-versa).

Propriétés de la transposée
PropriétéFormule
Double transposée(AT)T = A
Transposée d'une somme(A + B)T = AT + BT
Transposée d'un produit(A · B)T = BT · AT (ordre inversé !)
Transposée scalaire(k · A)T = k · AT
Note : (A·B)T = BT·AT — l'ordre s'inverse, comme pour l'inverse d'un produit !

📐Modélisation de systèmes linéaires

Forme matricielle A·X = B
Tout système de m équations à n inconnues s'écrit :

A · X = B

— A : matrice m×n des coefficients
— X : matrice colonne n×1 des inconnues
— B : matrice colonne m×1 des termes indépendants

Un client achète 10 articles de type A (5€) et B (6€) pour 56€ au total.

📊Évolution de populations

Modèle matriciel de dynamique
Pour i populations p₁, p₂, …, pᵢ :

P(n+1) = M · P(n)

— mjk : fraction de la population pk qui contribue à pj à la période suivante
— P(n) = Mⁿ · P(0)
Une distribution stable P* vérifie : P* = M · P*
(le vecteur ne change plus d'une période à l'autre)
Exemple complets — Deux comptes financiers

Comptes a et b : chaque année, 10% de a va vers b, 40% de b va vers a.

a(n+1) = 0.90·a(n) + 0.40·b(n)
b(n+1) = 0.10·a(n) + 0.60·b(n)
a(n+1) b(n+1)

Trouver la distribution stable

On cherche (x, y) tel que M·P = P, soit :

-0.10x + 0.40y = 0 ⟹ x = 4y
x + y = 11000 ⟹ 4y + y = 11000 ⟹ y = 2200
⟹ x = 8800
Distribution stable : a = 8 800 €, b = 2 200 € (rapport 4:1)

Exercice d'examen — Rongeurs (Juin 2018)

Trois classes : juvéniles j, préadultes p, adultes a. On cherche la matrice A tel que P(t+1) = A·P(t).

Voir les contraintes biologiques ▼
  • Juvéniles ne se reproduisent pas → a₁₁ = 0
  • Juvéniles ne peuvent pas rester juvéniles l'année suivante et ne peuvent pas devenir directement adultes → a₃₁ = 0
  • Préadultes ne peuvent pas rester préadultes → a₂₂ = 0
  • Adultes ne peuvent pas rajeunir → a₂₃ = 0
  • Rongeurs vivent max 3 ans → a₃₃ = 0
A = [ [0, a₁₂, a₁₃],
[a₂₁, 0, 0 ],
[0, a₃₂, 0 ] ]
Voir la résolution (données t=0→1) ▼

Observations : j(0)=60, p(0)=100, a(0)=80 → j(1)=860, p(1)=18, a(1)=60

100·a₁₂ + 80·a₁₃ = 860 → 5a₁₂ + 4a₁₃ = 43 (1)
60·a₂₁ = 18 → a₂₁ = 0.3
100·a₃₂ = 60 → a₃₂ = 0.6

Données t=1→2 donnent aussi : 3a₁₂ + 10a₁₃ = 79 (2)

Système (1),(2) → a₁₂ = 3, a₁₃ = 7
Résultat final ▼
037 0.300 00.60
A = [[0, 3, 7], [0.3, 0, 0], [0, 0.6, 0]]
a₁₂=3 préadultes et a₁₃=7 adultes produisent chacun des juvéniles

⚠ Pièges d'examen
1. Non-commutativité : A·B ≠ B·A en général

2. Zéro diviseurs : A·B = 0 n'implique pas A=0 ou B=0

3. Dimensions pour multiplication : vérifier col(A) = lig(B), pas l'inverse

4. Transposée d'un produit : (A·B)ᵀ = Bᵀ·Aᵀ (ordre inversé !)

5. Matrice identité : A·Iₙ = A seulement si A est m×n et I est n×n
